
# Brazilian E-Commerce Data Analysis

## 📌 Project Overview

This project focuses on analyzing the Brazilian E-Commerce dataset from Olist.

The project covers an end-to-end data analysis workflow, starting from data cleaning and exploratory data analysis using Python, followed by SQL analysis using MySQL and dashboard creation using Power BI.

## 🎯 Objectives

- Understand overall e-commerce sales performance
- Analyze customers, sellers and products
- Explore payment methods
- Analyze delivery performance
- Understand customer reviews
- Identify useful business insights from the data

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- MySQL
- SQL
- Power BI

## 🔄 Project Workflow

Raw Data
   ↓

   ↓

   ↓

## 🧹 Data Cleaning & EDA

Python was used to:

- Handle missing values
- Check duplicate records
- Correct data types
- Clean categorical data
- Perform exploratory data analysis
- Understand distributions and patterns
- Prepare the cleaned datasets for further analysis

## 🗄️ SQL Analysis

The cleaned datasets were imported into MySQL.

SQL was used to analyze:

- Orders and revenue
- Customers
- Products and categories
- Payment methods
- Delivery performance
- Customer reviews
- Sellers
- Repeat customers
- Multi-table relationships

## 📊 Power BI Dashboard

A Power BI dashboard was created to visualize the major findings from the analysis.

### Dashboard includes:

- Total Orders
- Total Revenue
- Total Customers
- Total Sellers
- Average Review Score
- Orders by Status
- Revenue by Payment Type
- Orders by Year
- Product Category Analysis
- Customer State Analysis
- Review Analysis
